# Feastcraft with Miri

The source for [feastcraftwithmiri.com](https://feastcraftwithmiri.com).

## Local development

```sh
npm install
npm run dev
```

## Adding recipes

Recipes live in `src/data/recipes`. They can be edited through Pages CMS or as Markdown files. Images are stored in `public/images/recipes`.

Only original Feastcraft recipes should include complete ingredients and instructions. Cookbook content should be presented as reviews, cooking experiences or links to the relevant book.
